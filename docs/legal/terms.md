# CoFit 用户协议

生效日期:2026-10-26

欢迎使用 CoFit(以下简称「本应用」)。本协议是你与开发者 PasserBo 之间关于使用本应用的约定。注册或使用本应用即表示你已阅读并同意本协议与[隐私政策](privacy.md)。

## 1. 服务内容

本应用提供「虚拟健身房」社交功能:你可以创建或加入房间,以虚拟小人的形式与好友共处一室,通过打出动作卡牌开始运动,并实时看到彼此的运动状态。本应用是一款激励工具,**不提供任何医疗或健身指导**,运动强度请根据自身状况决定。

## 2. 账号

- 你需要通过 Apple、Google(如开放)或邮箱注册账号。你对账号下的一切活动负责,请勿将账号交予他人。
- 一个人可持有多个账号,但不同登录方式之间的账号**不互通**。
- 你可以随时在「我的 → 删除账号」中删除账号,数据将按隐私政策所述永久清除。

## 3. 用户内容与社区规范

你在本应用中创建的昵称、房间名称与描述、自建动作卡等内容由你负责。你承诺不发布:

- 侮辱、骚扰、歧视、威胁他人的内容;
- 色情、暴力、违法或侵犯他人权利的内容;
- 冒充他人、垃圾信息或与健身无关的广告。

**举报与处理**:任何成员都可以在房间菜单中举报房间内容或某位成员。开发者会在收到举报后尽快审查;房主可以随时将成员移出房间。对违反本规范的账号,开发者有权移除内容、限制功能或注销账号,无需事先通知。

## 4. 房间

- 房间由创建者(房主)管理:房主可编辑房间信息、邀请成员、移出成员或解散房间。
- 持有邀请链接或房间 ID 的人可以加入「仅邀请」房间;请谨慎分享链接。
- 房间解散后,其内容不可恢复。

## 5. 知识产权

本应用的界面、图形、代码及官方动作卡内容归开发者所有。你对自己创建的内容保留权利,并授权本应用在提供服务所需的范围内展示这些内容。

本应用按「现状」提供。开发者不保证服务不中断或无错误,不对因使用本应用造成的运动伤害、数据丢失或其他损失承担责任(法律强制规定的除外)。实时同步依赖第三方服务(Firebase、Ably),其可用性不受开发者控制。

## 7. 服务变更与终止

开发者可随时更新、暂停或终止本应用的全部或部分功能。本协议如有重大变更,会在应用内或本页面公告。
