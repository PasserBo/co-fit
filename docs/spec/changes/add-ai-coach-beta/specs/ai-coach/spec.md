## Purpose

运动历史页里的 beta 功能「AI 教练」:用户就自己最近的运动记录提问,教练用文字或可交互的卡片回答。功能只对开放了 beta 的用户出现,会话不保存,但全过程留有可导出的日志。

## ADDED Requirements

### Requirement: 入口只对 beta 用户出现
运动历史页必须只在该用户开放了 beta 时显示「AI 教练 Beta」入口;未开放时页面与现在完全相同。

#### Scenario: 未开放 beta
- **GIVEN** 用户没有开放 beta
- **WHEN** 用户打开运动历史页
- **THEN** 页面上没有 AI 教练入口

#### Scenario: 已开放 beta
- **GIVEN** 用户开放了 beta
- **WHEN** 用户打开运动历史页(有记录或没有记录都一样)
- **THEN** 标题栏出现「AI 教练 Beta」入口,点击进入教练页

### Requirement: 首次使用前告知数据去向
用户第一次进入教练页时,必须先看到「最近的运动记录会发送给 AI 服务用于生成回答」的说明;用户同意之前不能提问,不同意则返回运动历史页。同意只需一次。

#### Scenario: 第一次进入
- **GIVEN** 用户从未同意过该说明
- **WHEN** 用户进入教练页
- **THEN** 先出现说明和「同意并继续」「返回」两个选择,输入框不可用

#### Scenario: 选择返回
- **GIVEN** 说明正在显示
- **WHEN** 用户选择「返回」
- **THEN** 回到运动历史页,没有任何记录被发送

#### Scenario: 同意之后再次进入
- **GIVEN** 用户之前已经同意过
- **WHEN** 用户再次进入教练页
- **THEN** 直接可以提问,不再出现说明

### Requirement: 教练依据最近的运动记录回答
教练必须只依据用户最近的运动记录(与运动历史页显示的同一批,最多 100 条)回答;没有记录时教练也必须能回答,并知道用户还没有记录。

#### Scenario: 询问本周情况
- **GIVEN** 用户本周完成过 3 次运动
- **WHEN** 用户问「这周练得怎么样」
- **THEN** 教练的回答与这 3 次运动一致(次数、动作名、时长)

#### Scenario: 没有任何记录
- **GIVEN** 用户还没有运动记录
- **WHEN** 用户提问
- **THEN** 教练正常回答,说明还没有记录,不编造记录

### Requirement: 提问方式
教练页必须提供几条预置问题和一个自由输入框;教练回答期间必须显示进行中,且不能再发起新的提问。

#### Scenario: 点预置问题
- **GIVEN** 教练页空闲
- **WHEN** 用户点一条预置问题
- **THEN** 该问题作为用户的发言出现在对话里,教练开始回答

#### Scenario: 回答进行中
- **GIVEN** 教练正在回答
- **WHEN** 用户尝试再点预置问题或发送
- **THEN** 不会发起新的提问

### Requirement: 卡片式回答可以交互
教练的回答可以包含卡片;卡片必须边生成边显示,卡片上的输入与按钮必须可用,点击按钮后教练必须收到该操作(连同卡片上填写的内容)并继续回答。卡片上的任何操作都不得改动用户的数据。

#### Scenario: 填写并提交卡片
- **GIVEN** 教练回了一张带单选和「提交」按钮的卡片
- **WHEN** 用户选中一项并点「提交」
- **THEN** 对话里注明已发送该操作,教练依据所选内容更新这张卡片或回一张新卡片

### Requirement: 失败时可以重新提问
请求失败或教练回的卡片无法显示时,对话里必须出现错误说明;用户随后必须可以重新提问。

#### Scenario: 网络断开
- **GIVEN** 设备离线
- **WHEN** 用户提问
- **THEN** 对话里出现请求失败的说明,进行中状态结束,用户可以再次提问

### Requirement: 对话不保存
离开教练页后对话必须清空;再次进入时是新的对话。

#### Scenario: 离开再回来
- **GIVEN** 用户和教练有过几轮对话
- **WHEN** 用户返回运动历史页后再次进入教练页
- **THEN** 对话为空

### Requirement: 导出本次会话日志
教练页必须提供「导出日志」,通过系统分享发出本次会话的完整日志(提问、回答、卡片、操作、错误与耗时);日志只保存在设备上,除非用户主动导出。

#### Scenario: 导出
- **GIVEN** 本次会话至少问过一个问题
- **WHEN** 用户点「导出日志」
- **THEN** 出现系统分享面板,分享内容是本次会话的日志文件
