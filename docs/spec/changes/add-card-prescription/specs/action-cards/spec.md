# Delta: action-cards

## Purpose
动作卡:一张卡告诉用户做什么、做多久、多大强度、做多少。

## ADDED Requirements

### Requirement: 卡片可以带「做多少」
一张卡必须可以带零项或多项量,每一项是一个数值加一个单位(次数、重量、距离);没有量的卡照常可用。

#### Scenario: 带两项量的卡
- **GIVEN** 一张卡带「12 个」和「2.5 kg」
- **WHEN** 用户在牌库、手牌或卡片详情里看这张卡
- **THEN** 卡上能看到「12 个 · 2.5 kg」

#### Scenario: 没有量的卡
- **GIVEN** 一张卡没有带任何量
- **WHEN** 用户看这张卡
- **THEN** 卡上只有名字、类型、时长和强度(如有),不出现空的量

### Requirement: 自建卡可以填量
用户创建或编辑自建卡时,必须能从量的种类里多选,并为每一种填一个大于 0 的数值;不填也能保存。

#### Scenario: 填次数和重量
- **GIVEN** 用户在创建卡片
- **WHEN** 用户选「次数」填 12,再选「重量」填 5,然后保存
- **THEN** 新卡上显示「12 个 · 5 kg」

#### Scenario: 去掉一项
- **GIVEN** 用户在编辑一张带「次数 12 个」的卡
- **WHEN** 用户再点一次「次数」并保存
- **THEN** 这张卡不再带次数

#### Scenario: 数值不合法
- **GIVEN** 用户在填某一种量
- **WHEN** 用户输入 0、负数或不是数字的内容
- **THEN** 不能确定,并提示输入大于 0 的数字

### Requirement: 量不改变运动的进行方式
卡上的量只是参考;打出一张卡后必须仍然按卡的时长倒计时,不要求用户确认做了多少。

#### Scenario: 打出带次数的卡
- **GIVEN** 一张 1 分钟、带「15 个」的卡
- **WHEN** 用户打出它
- **THEN** 倒计时 1 分钟后完成,期间和之后都不询问做了几个

### Requirement: 运动记录带着当时的强度与量
完成一张卡时,运动记录必须保存那一刻卡上的强度与量;之后这张卡被修改或删除,已有记录显示的内容不变。

#### Scenario: 回看
- **GIVEN** 用户完成了一张「中等、12 个」的卡
- **WHEN** 用户看运动历史
- **THEN** 这条记录显示「中等 · 12 个」

#### Scenario: 之后改了卡
- **GIVEN** 用户完成了一张「12 个」的自建卡,之后把它改成「20 个」
- **WHEN** 用户看以前那条记录
- **THEN** 仍然显示「12 个」

#### Scenario: 这个功能上线之前的记录
- **GIVEN** 一条以前的记录没有保存强度与量
- **WHEN** 用户看运动历史
- **THEN** 这条记录照常显示,只是不带强度与量

#### Scenario: 运动中 App 被结束
- **GIVEN** 用户打出一张带量的卡后 App 被系统结束,倒计时已过
- **WHEN** 用户重新打开 App
- **THEN** 补记的那条记录同样带着当时的强度与量
