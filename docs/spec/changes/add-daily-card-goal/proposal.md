# Proposal: 今日进度——今天出了多少、离目标还差多少,在今日面板里一眼可见,达成时小人庆祝

> State: idea · Updated: 2026-11-20

## Intent

CoFit 的社交玩法依赖好友在线;没人在线时,打开 App 只看到自己的小人,没有任何「今天该做点什么」的理由。运动记录现在藏在「我的」二级页,而且是回顾型的——用户已经练了才会去看。竞品里最被验证的单人留存机制,是一个**每天清零、默认目标低到第一天就能完成**的进度容器(Apple 三环、Duolingo 每日目标)。CoFit 的一次运动是一张约 1 分钟的卡,「今天出 2 张卡」是一个足够低、足够具体的目标。

怎么知道有效:上线后对比「有出牌的天数 / 活跃天数」与「单人(房间无人在线)时的出牌率」是否提升。

## Scope

In scope:
- 今日进度作为「今日面板」(`add-home-sheet`)的一个模块:当前进度 / 今日目标,每天在用户本地的零点清零;面板收起时是否还显示进度、显示在哪,跟随 `add-home-sheet` 收起态的决定。
- 用户可以调整今日目标。
- 达成目标的那一张卡完成时,自己的小人做一次庆祝动作,环闭合。
- 运动历史页顶部同步显示今日进度。
- 今天一张都没出时,模块引导到「今日推荐」。
- 计量方式(张数 / 分钟 / 其他)与目标值都是可替换的配置,换掉不需要改界面以外的代码;界面按「当前进度 / 目标」通用地展示。

Out of scope:
- 连胜、日历热力图(见 `add-workout-streak`)。
- 提醒通知(见 `add-workout-reminder`)。
- 好友能否看到我的今日进度(另议)。

## Capabilities
- `daily-goal`(new)

## Approach

今日进度由「计量方式」从运动记录算出,和「目标」比较后交给界面;计量方式、目标、展示三者互不依赖,任何一个都能单独替换(调研建议起步用张数,因为一张卡只有 30–90 秒,但这是内容选择,不是本 change 的约束)。庆祝动作复用小人现有的动作引擎。

## Decisions
- 2026-11-20: 由运动记录竞品调研(H1 + H5 的「摘要前移」部分)立为提案 — 没人在线时需要一个「今天该做点什么」的理由。
- 2026-11-20: 指标、目标值、规则参数都是**可随时调整的内容**,本系列不在提案里定死;要求系统足够解耦——计量方式、目标、连胜规则、解锁表、提醒文案各自独立可换,改一处不牵动其他部分 — 用户:先把系统做出来,再决定提供什么内容。
- 2026-11-20: 进度环位置不凭直觉定,先补竞品首屏 UI/UX 拆解(打开即看到成果 / 今日目标 / 开始入口的取舍) — 让用户愿意打开 App 是这个功能的核心。
- 2026-11-20: 今日进度不单独占首屏位置,作为今日面板的一个模块 — 用户选定 Finch 式下半部分面板方案。
