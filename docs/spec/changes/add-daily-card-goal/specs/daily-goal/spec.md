# Delta: daily-goal

## Purpose
今日进度:今天做了多少、离今日目标还差多少。每天清零,目标低到第一天就能完成,给没有好友在线的时候一个「今天做点什么」的理由。

## ADDED Requirements

### Requirement: 今日进度在今日面板里可见
今日面板必须有一个「今日进度」模块,显示今天的进度、今日目标和一个按比例填充的进度环;进度按完成的运动计算,没做完的不算。

#### Scenario: 今天做了一部分
- **GIVEN** 今日目标是 2,用户今天已完成 1 次运动
- **WHEN** 用户看今日面板
- **THEN** 模块显示 1 / 2,进度环填充一半,并提示还差 1

#### Scenario: 今天已经达成
- **GIVEN** 用户今天的进度已达到或超过今日目标
- **WHEN** 用户看今日面板
- **THEN** 进度环是闭合的,模块提示今日目标已达成
- **AND** 进度数字照实显示(可以大于目标)

#### Scenario: 运动记录还没加载完
- **GIVEN** 用户刚进入房间页,运动记录还在加载
- **WHEN** 今日面板出现
- **THEN** 今日进度模块显示占位,加载完后显示进度

#### Scenario: 运动记录加载失败
- **GIVEN** 运动记录加载失败
- **WHEN** 用户看今日面板
- **THEN** 今日进度模块不出现,其他模块照常

### Requirement: 今天还没开始时引导到今日推荐
用户今天一次都没完成时,今日进度模块必须提示从今日推荐开始,并且点它的效果与点「今日推荐」相同。

#### Scenario: 今天第一次打开
- **GIVEN** 用户今天还没完成过运动,手牌里有可推荐的卡
- **WHEN** 用户点今日进度模块
- **THEN** 面板收起,手牌进入选卡状态并停在今日推荐的那张卡上

#### Scenario: 没有可推荐的卡
- **GIVEN** 用户今天还没完成过运动,手牌是空的
- **WHEN** 用户看今日进度模块
- **THEN** 模块只显示 0 / 目标,不提示今日推荐
- **AND** 点模块正文没有反应

### Requirement: 进度每天在本地零点清零
今日进度必须只统计用户所在时区当天完成的运动;过了零点,进度从 0 重新开始,目标不变。

#### Scenario: 跨过零点
- **GIVEN** 用户昨天完成了 3 次运动,今天还没做
- **WHEN** 用户今天打开 App
- **THEN** 今日进度显示 0 / 目标

#### Scenario: App 开着过零点
- **GIVEN** App 停在房间页,今日进度是 2 / 2
- **WHEN** 时间过了零点
- **THEN** 今日进度变成 0 / 2,不需要重启 App

#### Scenario: 跨零点的一次运动
- **GIVEN** 用户在零点前开始一次运动,零点后完成
- **WHEN** 这次运动完成
- **THEN** 它计入完成那一天的进度

### Requirement: 用户可以调整今日目标
用户必须能在今日进度模块里从一组可选值中改今日目标;改完立即生效,之后每天沿用,直到再次修改。

#### Scenario: 调高目标
- **GIVEN** 今日目标是 2,今天已完成 2 次
- **WHEN** 用户把目标改成 3
- **THEN** 模块显示 2 / 3,进度环不再闭合,提示还差 1

#### Scenario: 调低目标到已完成的数量以下
- **GIVEN** 今日目标是 3,今天已完成 2 次
- **WHEN** 用户把目标改成 2
- **THEN** 模块显示 2 / 2,进度环闭合
- **AND** 不播放达成庆祝

#### Scenario: 没改过目标
- **GIVEN** 用户从没改过目标
- **WHEN** 用户看今日进度
- **THEN** 目标是默认值

#### Scenario: 换设备
- **GIVEN** 用户在一台设备上把目标改成 5
- **WHEN** 用户在另一台设备上登录
- **THEN** 另一台设备上的目标是默认值(目标只保存在本机)

### Requirement: 完成运动时进度跟着庆祝一起更新
用户完成一次运动并看到完成庆祝时,今日进度的数字和进度环必须在小人完成动作落地的那一下从旧值变到新值,而不是提前跳变。

#### Scenario: 完成一次,尚未达成
- **GIVEN** 今日进度是 0 / 2,面板收起
- **WHEN** 用户完成一次运动,面板升起、小人在面板上沿做完成动作
- **THEN** 小人落地时进度从 0 变为 1,进度环填充到一半

#### Scenario: 完成时没有播放庆祝
- **GIVEN** 完成庆祝没有播放(例如完成后展开被关闭,或记录来自另一台设备)
- **WHEN** 新的运动记录到达
- **THEN** 进度在短暂等待后直接更新为新值

### Requirement: 达成今日目标时有一次额外反馈
使今日进度第一次达到目标的那一次运动完成时,进度环必须闭合并给出一次明显的达成反馈(视觉强调与一次触感),模块提示今日目标已达成;同一天再完成运动不再重复这个反馈。

#### Scenario: 达成的那一次
- **GIVEN** 今日进度是 1 / 2
- **WHEN** 用户完成一次运动并看到完成庆祝
- **THEN** 进度变为 2 / 2,进度环闭合并播放一次达成反馈
- **AND** 模块提示今日目标已达成

#### Scenario: 达成之后继续运动
- **GIVEN** 今日进度是 2 / 2
- **WHEN** 用户又完成一次运动
- **THEN** 进度变为 3 / 2,不再播放达成反馈

#### Scenario: 减弱动态效果
- **GIVEN** 系统开启了「减弱动态效果」
- **WHEN** 进度变化或达成
- **THEN** 数字与进度环直接变到新值,不播放过渡与强调动画

### Requirement: 运动历史页顶部显示今日进度
运动历史页有记录时,顶部必须显示与今日面板一致的今日进度(进度、目标、进度环)。

#### Scenario: 打开运动历史
- **GIVEN** 用户有运动记录,今日进度是 1 / 2
- **WHEN** 用户打开运动历史页
- **THEN** 页面顶部显示 1 / 2 和填充一半的进度环

#### Scenario: 还没有任何记录
- **GIVEN** 用户从未完成过运动
- **WHEN** 用户打开运动历史页
- **THEN** 页面显示原有的空状态,不显示今日进度
