# Proposal: 房间页下半部分改为「今日面板」——打开就看到对自己有用的信息,收起后回到手牌

> State: in-progress · Updated: 2026-11-21

## Intent

房间页上半部分(房间与好友的小人)提供社交信息;下半部分是收起态的扇形手牌,几乎不提供信息,而且「打哪张」要用户自己决定。没有好友在线时,整个首屏没有任何关于「今天的我」的内容。Finch 把宠物和今日目标放在同一视线里,打开就知道今天该做什么——CoFit 也有小人,可以这样做。

本 change 把下半部分做成一个可收起的「今日面板」,面板里装什么**不固定**:内容由一个个独立的模块组成,哪些模块出现、顺序如何可以在不发版的情况下调整,用来测试用户更愿意在首屏看到什么。

怎么知道有效:不同面板布局下,打开 App 后出第一张卡的比例与耗时、面板模块的点击率、单人(房间无人在线)时的出牌率。

## Scope

In scope:
- 进入房间页时,下半部分默认显示今日面板,遮住收起态的扇形手牌;上半部分的房间、好友小人、左右滑切换房间不受影响,面板不是弹窗,不挡上半部分的操作。
- 收起面板后扇形手牌回来,原有出牌操作完全不变。
- 面板展开 = 自己的小人处于「被选中」状态;收起 = 取消选中。收起后点自己的小人重新展开。下半部分收起后与现在完全一样,不增加新的入口元素。
- 「被选中」的样子:面板像一个台子,自己的小人站在面板上沿的正中;未选中时小人回到房间里原来的位置漂浮。这个位置变化本身就是引导,不另加提示。运动中 / 暂停 / 待机时都可以上台,上台不打断正在做的动作。
- 动画(本 change 的重点):
  - 上台:点小人后小人先有反应,台子升起,小人落到台上并有落地感,面板里的模块随后依次出现。
  - 下台:小人起跳离开台子回到原位,台子降下,手牌回来。下拉把手时小人跟着台子一起下降,松手确认收起后才离开。
  - 今日推荐:面板收起,手牌进入选择状态且推荐的卡在正中(卡片飞行暂不做)。
  - 完成一张卡:台子升起接住小人,小人在台上做完成庆祝,今日进度等模块的数字同步变化。
  - 动画播完前不接受新的点击或拖动;系统开启「减弱动态效果」时改为简单的淡入淡出。
- 收起面板的方式:下拉面板把手、再点一次自己的小人、点房间空白处、点「今日推荐」。打开 / 收起都不依赖从屏幕最底边上滑,避免和系统回到主屏幕的手势冲突。
- 第一个模块「今日推荐」:展示一张推荐的卡;点它 → 面板收起、手牌进入选择状态,且推荐的卡已经在正中,再上滑即可打出。
- 面板里的模块可以独立增删、排序,每个模块在没有数据或出错时自行隐藏或显示占位,不影响其他模块。
- 面板的模块组成、顺序、默认展开与否可以远程调整,不需要发新版本。
- 左右滑切换房间时,自己的小人固定不动,只有房间和好友在滑(展开、收起时都一样)。
- 面板自动展开的规则可配置,默认:冷启动、离开一段时间后回到前台、完成一张卡。
- 卡在用户没看着时做完(后台、锁屏),下次回到房间页补播一次完成庆祝,多次合并为一次。

Out of scope:
- 具体放哪些模块、推荐算法、显示什么指标——都是可替换的内容(今日进度见 `add-daily-card-goal`,连胜见 `add-workout-streak`)。
- 首屏之外的入口(通知、小组件)。
- 让用户自己定制面板。
- 使用数据统计(比较不同布局的效果)——另见 `add-usage-analytics`。

## Capabilities
- `home-sheet`(new)

## Approach

面板是一个容器,只负责展开 / 收起、排列模块;每个模块自己取数据、自己画、自己决定是否显示,和房间页之间只通过少数几个动作交互(收起面板、让手牌聚焦到某张卡、打开某个页面)。模块清单与布局由一份远程可调的配置决定,本地带一份默认值,远程未配置或读取失败时用默认值。

## Decisions
- 2026-11-20: 采用 Finch 式思路,在房间页下半部分做可收起的「今日面板」,收起后回到扇形手牌 — 下半部分的收起态手牌几乎不提供信息量。
- 2026-11-20: 面板内容不固定,做成可独立替换的模块,布局可远程调整,以便测试用户更喜欢首屏看到什么 — 先做出系统,内容后定。
- 2026-11-20: 「今日推荐」模块点开后收起面板、手牌聚焦并把推荐卡放在正中 — 面板遮住了手牌,要给出直达出牌的路径。
- 2026-11-20: 重新打开面板不使用「从底边上滑」 — 会和系统回到主屏幕的手势冲突。
- 2026-11-20: 收起态不用「手牌上方的摘要小胶囊」做入口 — 用户不喜欢这个设计,要求重新考虑。
- 2026-11-20: 重新打开面板的方式定为点自己的小人;引导靠小人明显的「被选中」状态,不另加提示元素 — 用户决定;三个候选(托盘 / 今日卡 / 点小人)中选了点小人。
- 2026-11-21: 「被选中」状态定为小人站到面板上沿,面板像台子;动画是这个设计的重点 — 用户决定(三个候选:脚下选中环 / 站到面板上 / 面板尖角)。
- 2026-11-21: 动画编排方向确认:上台、下台、今日推荐、完成庆祝四段,细节见 design.md — 用户看过可点击原型后确认。
- 2026-11-21: 切换房间时自己的小人固定不动 — 台子不随房间滑动,未选中时保持一致;自己的状态本来就同步到所有房间。
- 2026-11-21: 点房间空白处也收起面板 — 符合「选中」的通常习惯,误触后点一下小人即可恢复。
- 2026-11-21: 不在看时完成的卡,回来补播一次庆祝,多次合并 — 做运动时手机常在后台或锁屏。
- 2026-11-21: 自动展开做成可配置规则,默认为冷启动、隔一段时间回到前台、完成一张卡 — 参数是内容,先给默认值。
- 2026-11-21: 使用数据统计不阻塞本 change,另开 `add-usage-analytics` — 先把面板做出来。
- 2026-11-21: 提案 accepted — 用户:按建议定。
- 2026-11-21: 今日推荐先不做卡片飞行,点了只收起面板并展开手牌 — 用户在模拟器试用:飞出来的是一个绿框而不是卡,观感怪;卡牌动画以后单独优化。
- 2026-11-21: 动画必须播完才能进行下一个操作(取代之前「动画进行中再次点击或拖动要立即响应」)— 用户试用后决定。
