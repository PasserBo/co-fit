## Purpose
登录用户自己创建一个房间:在一个完整的页面里填好房名、简介和谁能找到它,建好之后直接进入这个房间,并被提示可以把房间分享给朋友。

## ADDED Requirements

### Requirement: 新建房间入口
用户必须能从以下位置打开「新建房间」页面:没有任何房间时的房间页空态、「我的房间」页、「我的」页的房间分组、「发现房间」页。

#### Scenario: 没有房间时新建
- **GIVEN** 用户没有加入任何房间
- **WHEN** 用户在房间页点「新建房间」
- **THEN** 打开「新建房间」页面

#### Scenario: 从「我的」页新建
- **GIVEN** 用户在「我的」页
- **WHEN** 用户点房间分组里的「新建房间」
- **THEN** 打开「新建房间」页面

### Requirement: 新建房间表单
「新建房间」页面必须包含房名(必填,最多 30 个字)、简介(可选,最多 120 个字)和可见性(「公开」或「仅邀请」,默认「公开」),并对每种可见性说明谁能找到这个房间。房名去掉首尾空白后为空时,创建按钮必须不可点。

#### Scenario: 默认值
- **GIVEN** 用户打开「新建房间」页面
- **THEN** 房名与简介为空,可见性选中「公开」,创建按钮不可点

#### Scenario: 只输入空格
- **GIVEN** 用户在房名里只输入了空格
- **THEN** 创建按钮仍不可点

#### Scenario: 超过字数
- **GIVEN** 房名已有 30 个字
- **WHEN** 用户继续输入
- **THEN** 多出的字不会被输入

### Requirement: 创建后直接进入房间
创建成功后,App 必须关闭「新建房间」页面及其下方打开的房间相关页面,回到房间页并显示刚建好的房间,同时在房间页上弹出「房间已就绪」卡片,提供分享邀请链接、复制链接和关闭(先进房间看看)。

#### Scenario: 创建成功
- **GIVEN** 用户填好房名并点「创建并进入」
- **WHEN** 服务器接受创建
- **THEN** 房间页显示该房间,用户是房主
- **AND** 房间页上出现「房间已就绪」卡片,可以分享或复制邀请链接
- **AND** 关闭卡片后停留在该房间

#### Scenario: 从「我的」页创建
- **GIVEN** 用户从「我的」页打开「新建房间」并创建成功
- **THEN** App 切换到房间页并显示该房间

### Requirement: 创建失败
创建过程中按钮必须显示进行中且不能重复点击;创建失败时页面必须保留用户已填的内容并显示失败原因,用户可以再次点创建。

#### Scenario: 网络失败
- **GIVEN** 设备离线
- **WHEN** 用户点「创建并进入」
- **THEN** 页面停留,填写内容不丢失,显示创建失败
- **AND** 恢复网络后再次点击可以创建成功

#### Scenario: 连点
- **GIVEN** 创建请求进行中
- **WHEN** 用户再次点击创建按钮
- **THEN** 不会创建第二个房间
