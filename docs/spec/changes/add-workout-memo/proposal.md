# Proposal: 运动 memo——做完一张卡顺手记一句,之后能回看、能改

> State: in-progress · Updated: 2026-11-25

## Intent

运动记录现在只有「哪张卡、多久、什么时候」,用户自己的东西一点都留不下来,回看也只是一张不能点的列表。把 CoFit 当作运动 memo App 来看,缺两样:**记下来**(做完时的感受、一句话)和**回头看得到、改得了**。

难点是一张卡只有约一分钟,打完就走。所以 memo 必须零必填、第一层只要一次点击,并且出现在用户本来就在看的地方——完成时升起的今日面板。

怎么知道有效:完成后点了感受的比例;有 memo 的记录占比;运动记录页的打开次数(依赖 `add-usage-analytics`)。

## Scope

In scope:
- 完成一张卡后,今日面板最上方出现「刚才这张」:一次点击记感受;可选写一句话。全部可跳过。
- 完成后一段时间内(包括离开 App 再回来)都还能补记,过后不再追问。
- 运动历史页的记录行露出 memo,并且可以点开:看完整 memo,改感受 / 文字,删除 memo。
- 今日面板的今日进度可点,一步到达运动历史页。
- 感受的档位与文案、可补记的时长、文字长度上限都是可替换的内容。

Out of scope:
- 做了多少(次数 / 距离 / 重量):不在完成后填,属于卡片本身的信息(`add-card-prescription`)。
- 下次出这张卡时显示「上次」(调研 §9 方案三)——另立。
- 记录的专门页面 / 小人页(`add-character-page`)。
- 把连续几张卡合并成「一次运动」只问一次;标签;照片。
- 删除运动记录本身(记录只增不删)。
- 好友能否看到我的 memo。

## Capabilities
- `workout-memo`(new)

## Approach

memo 与运动记录分开保存:记录是只追加、不可改的日志,memo 要能补写、修改、删除,所以放在自己的地方,以记录的 id 为键,不放宽记录本身的权限。服务端权限规则需要新增一段(按惯例先给用户看 diff,推送 main 后由 CI 部署);账号删除要把 memo 一并清掉。界面上,记的入口是今日面板的一个新模块,看和改的入口是运动历史页的行。

## Decisions
- 2026-11-25: 立项并开始实现 — 用户:调研后只做了今日推荐,运动 memo 的设计与实装完全没有进行;采用调研 §9 的方案一,先把它做完。
- 2026-11-25: 起步内容(都可在配置里换):感受三档「轻松 / 刚好 / 吃力」;完成后 30 分钟内可在面板里补记;一句话最多 100 字 — agent 取的默认值,用户未逐项确认。
- 2026-11-25: 每张卡单独问,不合并连续几张 — agent 的默认做法(调研标为不确定项),用户未确认。
- 2026-11-25: 「我的」页里两行入口暂不改名 — 入口的整体调整在 `add-character-page` 里做。
- 2026-11-25: 去掉完成后填次数(已实现的次数输入、数据字段、规则一并删除)— 用户:次数不应该是运动完后才填的东西;原本的设计是卡片数据里就带强度和一个大致的描述(次数 / 距离 / 重量等),而不是现在只有时间。卡片一侧另立 `add-card-prescription`。
