# Delta: workout-memo

## Purpose
运动 memo:做完一张卡后顺手记下感受或一句话,之后在运动历史里能看到、能修改。全部可选,不写不影响任何事。

## ADDED Requirements

### Requirement: 完成一张卡后今日面板出现「刚才这张」
用户完成一张卡后,今日面板最上方必须出现一个针对这张卡的 memo 模块,显示卡名和可选的感受档位;用户不做任何操作也不受阻碍。

#### Scenario: 刚做完
- **GIVEN** 用户完成了一张卡
- **WHEN** 今日面板升起
- **THEN** 面板最上方出现「刚才」模块,显示这张卡的名字和感受档位
- **AND** 今日进度、今日推荐照常显示在它下面

#### Scenario: 什么都不记
- **GIVEN** 「刚才」模块正在显示
- **WHEN** 用户收起面板、切换页面或直接打出下一张卡
- **THEN** 没有任何提示或确认,这次运动的记录照常保留

#### Scenario: 连续做了两张
- **GIVEN** 用户完成了一张卡且没有记 memo
- **WHEN** 用户又完成了另一张卡
- **THEN** 「刚才」模块改为针对最新的那一张

#### Scenario: 今天还没做过
- **GIVEN** 用户最近一次完成运动已经超过可补记的时长
- **WHEN** 用户看今日面板
- **THEN** 不出现「刚才」模块

### Requirement: 一次点击记下感受
用户点一个感受档位,必须立即记下并显示为已选中,不需要再点保存。

#### Scenario: 点一个档位
- **GIVEN** 「刚才」模块正在显示,还没有记过
- **WHEN** 用户点「刚好」
- **THEN** 「刚好」显示为选中,memo 已保存

#### Scenario: 改选
- **GIVEN** 已选中「刚好」
- **WHEN** 用户点「吃力」
- **THEN** 选中的变成「吃力」

#### Scenario: 取消选择
- **GIVEN** 已选中「刚好」,没有写文字
- **WHEN** 用户再点一次「刚好」
- **THEN** 没有任何档位被选中,这条 memo 不再存在

#### Scenario: 保存失败
- **GIVEN** 设备没有网络且保存没有成功
- **WHEN** 用户点一个档位
- **THEN** 选中状态回到点之前,并提示没有保存成功

### Requirement: memo 不问做了多少
memo 必须只记感受和文字;做了几个、多远、多重这类「量」不在完成后填写。

#### Scenario: 任何一张卡
- **GIVEN** 用户完成了任意一张卡
- **WHEN** 「刚才」模块出现
- **THEN** 模块里只有感受档位和「写一句」,没有次数、距离、重量的输入

### Requirement: 可以写一句话
用户必须能为这次运动写一段短文字;文字有长度上限,超出时不能保存。

#### Scenario: 写一句
- **GIVEN** 「刚才」模块正在显示
- **WHEN** 用户点「写一句」,输入文字并保存
- **THEN** 模块里显示这句话的开头

#### Scenario: 清空文字
- **GIVEN** 这条 memo 只有文字
- **WHEN** 用户在运动历史里删除这条 memo
- **THEN** 这条 memo 不再存在,运动记录还在

### Requirement: 完成后一段时间内可以补记
用户完成一张卡后离开(包括关掉 App),在可补记的时长内回来时,今日面板必须仍然显示针对那张卡的「刚才」模块以及已经记下的内容;超过时长后模块不再出现。

#### Scenario: 离开一会儿再回来
- **GIVEN** 用户完成一张卡后没有记 memo 就关掉了 App
- **WHEN** 用户在可补记的时长内重新打开 App
- **THEN** 今日面板里仍有针对那张卡的「刚才」模块

#### Scenario: 已经记过
- **GIVEN** 用户已经为刚才那张卡选了感受
- **WHEN** 用户在可补记的时长内再看今日面板
- **THEN** 「刚才」模块显示已选中的感受,可以继续改

#### Scenario: App 开着超过时长
- **GIVEN** 「刚才」模块正在显示
- **WHEN** 时间超过了可补记的时长
- **THEN** 模块消失,不需要重启 App

### Requirement: 运动历史里看得到 memo
运动历史页的每条记录必须在同一行露出它的 memo:感受、文字的开头;没有 memo 的记录保持原样。

#### Scenario: 有 memo 的记录
- **GIVEN** 一条记录记了「吃力」和一句话
- **WHEN** 用户看运动历史
- **THEN** 这一行显示「吃力」和那句话的开头

#### Scenario: memo 加载失败
- **GIVEN** memo 没有加载成功
- **WHEN** 用户看运动历史
- **THEN** 记录照常显示,只是不带 memo

### Requirement: 运动历史里可以补记和修改
用户点运动历史里的任意一条记录,必须能看到完整的 memo 并修改感受、文字,或删除整条 memo;运动记录本身不能在这里删除。

#### Scenario: 给以前的记录补记
- **GIVEN** 一条三天前的记录没有 memo
- **WHEN** 用户点开它并选了「轻松」
- **THEN** 回到列表后这一行显示「轻松」

#### Scenario: 删除 memo
- **GIVEN** 一条记录有 memo
- **WHEN** 用户点开它并删除 memo
- **THEN** 这一行不再显示 memo,记录还在

### Requirement: 从今日面板一步到达运动历史
今天已经完成过运动时,用户点今日面板里的今日进度必须直接打开运动历史页。

#### Scenario: 今天做过
- **GIVEN** 今日进度是 1 / 2
- **WHEN** 用户点今日进度
- **THEN** 打开运动历史页

#### Scenario: 今天还没做
- **GIVEN** 今日进度是 0 / 2
- **WHEN** 用户点今日进度
- **THEN** 仍然是引导到今日推荐,不打开运动历史页

### Requirement: 删除账号时 memo 一并删除
用户删除账号时,他写过的所有 memo 必须和其他数据一起被删除。

#### Scenario: 删除账号
- **GIVEN** 用户写过 memo
- **WHEN** 用户完成账号删除
- **THEN** 这些 memo 不再存在
